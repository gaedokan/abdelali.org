Signing out removes the copy stored on this device (after syncing it). “Everywhere” also signs out every other phone or computer — use it if a device is lost. To change your passphrase, update the BUDGET_PASSWORD secret in Cloudflare: that signs everyone out too.

Log Apple Wallet payments automatically

On iPhone (iOS 17 or later), a personal automation can send every Apple Pay payment straight to this budget. It shows up in the account with a Wallet badge, categorised from the payee’s last category, ready for you to approve.

  1. Open Shortcuts → Automation → + → Transaction. Choose your cards, keep the other options, and pick Run Immediately.
  2. Add the action Get Contents of URL:
    URL{{ endpoint }} MethodPOST HeadersAuthorization: Bearer your wallet token (or your passphrase) Request bodyJSON — amount = Shortcut Input › Amount, merchant = Merchant, card = Card or Pass › Name
  3. Optional: add Get Dictionary Value “message” from the result, then Show Notification, so you see e.g. “Spent 45,00 MAD at Carrefour → Groceries”.
  4. Make sure each account’s iPhone Wallet card names (Edit account) match your card names, so payments land in the right account.

Tip: for a token that can only add transactions, set a separate BUDGET_WALLET_TOKEN secret on the server and use it in the shortcut instead of your password.

For cash, add a home-screen shortcut with an “Open URL” action like {{ addLink }}, which opens Quick add pre-filled.
